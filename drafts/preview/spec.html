Invariants

Plans expire

A plan snapshot is only valid for its declared TTL, never indefinitely.

Commit is enumerated

Execution accepts only the exact approved action ids for one plan digest.

No silent mutation

Every state-changing call happens inside a named action with a receipt.

Spec (schema) — plan action fields

id: string

Unique action id within the plan, kebab-case.

kind: "content_put" | "publish_page" | "deploy_page"

Discriminates the action's shape.

dependsOn: string[]

Other action ids that must complete first.
